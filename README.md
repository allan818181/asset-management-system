# Asset Management System

## Project Description

We have developed an Asset Management System using the Django web framework to provide an efficient and centralized platform for managing organizational assets. The system is designed to help institutions and organizations record, monitor, and control assets throughout their lifecycle, from acquisition and allocation to maintenance and disposal.

The system enables administrators to register assets, assign them to employees or departments, track their locations, monitor maintenance activities, and manage disposal records when assets become obsolete or unusable. By digitizing these processes, the system improves accountability, reduces asset loss, and enhances operational efficiency.

## Problem Statement

Many organizations still manage assets manually using paper records or spreadsheets, which can lead to data inconsistency, poor tracking, loss of assets, and difficulty in monitoring maintenance schedules. These challenges reduce efficiency and may result in unnecessary operational costs.

This project addresses these challenges by providing a computerized asset management solution that offers secure storage, easy retrieval, and effective monitoring of asset-related information.

## Objectives

The main objective of this project is to develop a web-based system for efficient asset management.

Specific objectives include:

* To register and maintain records of organizational assets
* To track asset allocation to employees and departments
* To monitor asset maintenance and servicing records
* To store supplier and location information
* To manage disposal records for retired assets

## Main Features

The Asset Management System provides the following features:

* Asset registration and categorization
* Employee and department management
* Asset assignment tracking
* Maintenance history management
* Supplier management
* Asset location management
* Disposal record management
* Administrative dashboard for system control

## Installation Guide

To run this project locally:

1. Clone or download the project repository
2. Create and activate a virtual environment
3. Install dependencies using:

```bash
pip install -r requirements.txt
```

4. Apply database migrations:

```bash
python manage.py migrate
```

5. Start the development server:

```bash
python manage.py runserver
```

6. Open the browser and access:

http://127.0.0.1:8000/
